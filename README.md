# Yatube API на FastAPI

Проект по переносу функционала социальной сети Yatube с Django на FastAPI. В репозитории представлена история разработки, разделенная на 6 этапов (коммитов).

## 📂 Этапы разработки (Задания)
История коммитов отражает последовательное выполнение заданий:

1.  **Задание 1**: Инициализация FastAPI приложения, перенос моделей из Django (SQLAlchemy) и асинхронная архитектура.
2.  **Задание 2**: Реализация асинхронных репозиториев для работы с PostgreSQL.
3.  **Задание 3**: Настройка Alembic для автоматического управления миграциями.
4.  **Задание 4**: Централизованная обработка ошибок во всех слоях и кастомная валидация через Pydantic.
5.  **Задание 5**: Система аутентификации и авторизации на основе JWT токенов.
6.  **Задание 6**: Докеризация проекта, настройка логирования, реализация загрузки изображений и тестирование через pytest.

## 🚀 Как запустить

### Через Docker (рекомендуется)
1. Склонируйте репозиторий и перейдите в корень проекта.
2. Запустите контейнеры:
   ```bash
   docker-compose up --build
   ```
3. API будет доступно по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)
4. Документация Swagger: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

### Локальный запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Настройте подключение к PostgreSQL в файле `.env`.
3. Примените миграции:
   ```bash
   alembic upgrade head
   ```
4. Запустите сервер:
   ```bash
   uvicorn src.main:app --reload
   ```

## 🛠 Стек технологий
*   **FastAPI** — веб-фреймворк (асинхронный)
*   **SQLAlchemy (Async)** — ORM для работы с БД
*   **PostgreSQL** — основная база данных
*   **Alembic** — миграции
*   **Pydantic v2** — валидация данных и схемы
*   **python-jose** — работа с JWT токенами
*   **Docker & Docker Compose** — контейнеризация
*   **Pytest & httpx** — автоматизированное тестирование
*   **aiofiles** — асинхронная работа с файлами (изображения)
